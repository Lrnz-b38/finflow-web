## 🛠️ Technology Stack

### Frontend
```
React 18 + TypeScript + Tailwind CSS
├── Vite (Build)
├── React Router (Navigation)
├── Lucide Icons (UI Icons)
└── Context API (State)
```

```
Node.js + Express + MongoDB
├── Mongoose (ODM)
├── JWT (Auth)

```

### Database
```
MongoDB
├── User Collection
├── LinkedAccount Collection
└── Transaction Collection
```
